Mac

{% if 'mac-arm64' in available or 'mac-x86_64' in available %}
{% if 'mac-arm64' in available %}Download for Apple silicon (M1 or newer){% endif %} {% if 'mac-x86_64' in available %}Download for Intel Mac{% endif %}

Not sure which? Apple menu → About This Mac. "Chip: Apple M…" means Apple silicon; "Processor: Intel" means Intel.

  1. Open the downloaded file and drag RustDesk into Applications. Then open RustDesk from Applications.
  2. Click Copy server settings below.
  3. In RustDesk, open Settings → Network, click Unlock Network Settings, then click ID/Relay Server. Click the paste icon (Import server config), then OK.
  4. When RustDesk asks, allow Accessibility and Screen Recording in System Settings → Privacy & Security. Without them, IT can't see or control the screen.
  5. Send your IT contact the ID shown in RustDesk.
